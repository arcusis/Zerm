Enhancement settings are useful to change at exactly the moment you are dictating —
which is the worst moment to open a settings window. These two shortcuts let you change
them from the recorder instead.

Both only work **while the recorder is visible**. That is deliberate: they use keys that
would otherwise collide with the app you are typing into, so they are live only during
the few seconds the recorder is on screen.

![The recorder with prompts showing](img/enhancement-shortcuts.png)

## Toggle enhancement — ⌘E

Turns [AI enhancement](enhancement.html) on or off for the recording in progress. The
recorder shows the current state, so you can see what you changed.

Use it when your default is right most of the time but wrong for this particular
sentence — a name you want left exactly as you said it, or a quick note that does not
need cleaning up.

The binding is ⌘E by default and can be changed.

## Switch prompt — ⌘1 to ⌘0

Selects one of your first ten enhancement prompts, in the order they are saved. ⌘1 is
the first, ⌘0 the tenth.

To change which prompt sits on which key, reorder your prompts. There is no separate
binding per prompt.

Selecting a prompt this way also turns enhancement on, since choosing a prompt with
enhancement off would do nothing.

## Which ⌘1–⌘0 does what

The number keys drive whatever the recorder is currently showing. When it is showing
enhancement prompts, they select prompts. When it is showing
[Power Modes](power-mode.html), they select modes.

## Other ways to change the same things

**Trigger words.** Start a transcript with a prompt's trigger word and Zerm switches to
that prompt automatically, strips the trigger, and restores your previous setting
afterwards. No keys at all.

**Power Mode.** Pin a prompt to an app or website and it switches itself whenever you go
there. Better than a shortcut for anything you do repeatedly.

**Output mode.** If you find yourself switching enhancement off constantly, the setting
you want is probably [Instant](output-modes.html) rather than a faster way to turn it
off.

The full shortcut list is on the [keyboard shortcuts](shortcuts.html) page.
