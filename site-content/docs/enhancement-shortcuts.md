Enhancement settings are useful to change at exactly the moment you are dictating —
which is the worst moment to open a settings window. These shortcuts let you change
them from the recorder instead.

They only work **while the recorder is visible**. That is deliberate: they use keys that
would otherwise collide with the app you are typing into, so they are live only during
the few seconds the recorder is on screen.

Whatever you change applies to the recording in progress only. Your global settings and
your [Power Modes](power-mode.html) are left exactly as they were.

## Toggle AI Enhancement — ⌘E

Switches [AI enhancement](enhancement.html) on or off for the recording in progress. The
recorder shows the current state, so you can see what you changed.

- If this recording would use AI, ⌘E switches it to **Instant**.
- If it would not, ⌘E switches it to the AI output you used last — Instant + Refine
  unless you have used Enhanced.

Use it when your default is right most of the time but wrong for this particular
sentence — a name you want left exactly as you said it, or a quick note that does not
need cleaning up.

The binding is ⌘E by default and can be changed.

Screen context is only captured when a recording starts in Enhanced, so switching to
Enhanced with ⌘E mid-recording enhances without it. See
[contextual awareness](contextual-awareness.html).

## Switch Enhancement Prompt — ⌘1 to ⌘0

Selects one of your first ten enhancement prompts, in the order they are saved. ⌘1 is
the first, ⌘0 the tenth.

To change which prompt sits on which key, reorder your prompts. There is no separate
binding per prompt.

Selecting a prompt this way also turns enhancement on for a recording that was on
Instant, since choosing a prompt with enhancement off would do nothing.

## Power Modes — ⌥1 to ⌥0

The Option number keys select one of your first ten enabled
[Power Modes](power-mode.html) for the recording in progress. Command selects prompts;
Option selects modes.

## Other ways to change the same things

**Power Mode.** Set the output or pin a prompt for an app or website and it applies
whenever you go there. Better than a shortcut for anything you do repeatedly.

**Output mode.** If you find yourself switching enhancement off constantly, the setting
you want is probably [Instant](output-modes.html) rather than a faster way to turn it
off.

The full shortcut list is on the [keyboard shortcuts](shortcuts.html) page.
